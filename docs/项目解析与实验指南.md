# MeaCapInvLM_origin_v1：代码解析与训练 / 推理实验指南

面向分支 [`MeaCapInvLM_origin_v1`](https://github.com/chenaying/meacapInvLM/tree/MeaCapInvLM_origin_v1)。  
本仓库 = **ViECap 解码器（可训练）** + **MeaCap InvLM 记忆检索硬提示（仅推理）**。

上游参考：

- ViECap：[FeiElysia/ViECap](https://github.com/FeiElysia/ViECap)  
- MeaCap：[joeyz0z/MeaCap](https://github.com/joeyz0z/MeaCap)  
- 本仓库：[chenaying/meacapInvLM](https://github.com/chenaying/meacapInvLM)

---

## 1. 项目在做什么

| 阶段 | 做什么 | 硬提示从哪来 |
|------|--------|----------------|
| **训练** | 学 CLIP→GPT-2 的 mapping +（可选）微调 GPT-2 | 训练数据里的实体 / hard prompt（ViECap 数据管线） |
| **ViECap 推理** | 图像 CLIP 特征 → soft prompt；词表分类 → hard prompt | `coco_entities` 等 + CLIP 相似度 |
| **MeaCap InvLM 推理** | soft prompt 同上；hard prompt 换为记忆库 retrieve-then-filter | HF CLIP 检索 `data/memory/{id}` → 场景图解析 → 概念过滤 |

**重要：** InvLM **不改变训练目标**。论文中的 \(MeaCap_{InvLM}\) 是在已训练的 ViECap 权重上，**推理阶段**用记忆模块替换实体分类器。

## 2. 目录与模块解析（本分支现状）

```text
MeaCapInvLM/
├── main.py / CaptionsDataset.py / ClipCap.py   # 训练入口与模型
├── validation.py                               # 批量评测（ViECap / InvLM）
├── viecap_inference.py                         # InvLM 单图推理
├── infer_by_instance.py / infer_by_batch.py    # ViECap 单图 / 批量推理
├── search.py                                   # greedy / beam / OPT 解码
├── retrieval_categories.py                     # ViECap 实体分类
├── meacap_utils/                               # InvLM：检索 + 场景图 + 硬提示拼接
│   ├── invlm_prompt.py                         # MeaCapInvLMResources、retrieve、build_embeddings
│   ├── detect_utils.py                         # retrieve_concepts
│   └── parse_tool.py                           # 文本场景图解析
├── models/clip_utils.py                        # 记忆检索用 HuggingFace CLIP
├── evaluation/cocoeval.py                      # CIDEr 等指标
├── scripts/
│   ├── train_coco.sh / train_flickr30k.sh
│   ├── eval_coco.sh / eval_flickr30k.sh / eval_nocaps.sh          # ViECap 基线
│   ├── eval_flickr30k_meacap.sh / eval_nocaps_meacap.sh           # InvLM 批量
│   └── run_meacap_invlm.sh                                         # InvLM 单图
├── annotations/   # 本地数据（一般不进 Git）
├── checkpoints/   # 训练权重 coco_prefix-*.pt
└── data/memory/{coco,flickr30k,...}/           # 记忆库三件套
```

### 2.1 核心数据流（推理）

```text
原图
  ├─(OpenAI CLIP / pickle)─► mapping_network ─► soft prompt (连续向量)
  └─(HF CLIP，仅 InvLM)────► 与 memory_clip_embeddings 相似度
                              ─► top-K caption ─► Flan-T5 解析 + MiniLM 过滤
                              ─► 概念列表 ─► GPT word_embed ─► hard prompt
soft + hard（默认 soft 在前）─► GPT-2 解码 ─► caption
```

### 2.2 双 CLIP（读懂报错的关键）

| 用途 | 编码器 | 数据 |
|------|--------|------|
| Soft prompt / ViECap 训练特征 | OpenAI CLIP `ViT-B/32` | `*_ViT-B32.pickle` |
| InvLM 记忆检索 | HF CLIP（与记忆库一致） | 磁盘原图 + `memory_clip_embeddings.pt` |

因此：只有 pickle、没有原图时，**ViECap 基线可跑**；**InvLM 默认仍需要原图**（本分支未再包含 `update_2` 的无图 fallback 脚本）。

### 2.3 本分支相对 `update_2` 的差异（实验相关）

- **有** `eval_flickr30k_meacap.sh`、`eval_nocaps_meacap.sh`、`run_meacap_invlm.sh`  
- **无** `eval_coco_meacap.sh`、NoCaps 整理/HF 特征导出脚本、无图 InvLM 参数  
- COCO 上跑 InvLM：需直接调 `validation.py --use_meacap_invlm`（见下文）

## 3. 环境与数据准备

### 3.1 环境

```bash
conda activate meacap   # 或按 requirements.txt 自建
cd ~/project/MeaCap_InvLM   # 服务器示例路径
git checkout MeaCapInvLM_origin_v1
```

依赖概要：PyTorch、`openai/CLIP`、`transformers`、`sentence-transformers`、评测用 `evaluation/`。

### 3.2 权重与标注（本地，通常不进 Git）

1. **ViECap** [checkpoints.zip](https://github.com/FeiElysia/ViECap/releases/tag/checkpoints)  
   → `checkpoints/`、`annotations/`（含评测 pickle、词表 embedding）
2. **MeaCap 记忆库** [HuggingFace JoeyZoZ/MeaCap memory](https://huggingface.co/JoeyZoZ/MeaCap/tree/main/memory)  
   → `data/memory/coco/`、`data/memory/flickr30k/` 等，各含：  
   `memory_captions.json`、`memory_clip_embeddings.pt`、`memory_wte_embeddings.pt`
3. **离线模型**（teacher5 示例，可用环境变量覆盖）：

```bash
export LANGUAGE_MODEL=/home/teacher5/data1/cyp/project/NewCap/gpt2
export VL_MODEL=/home/teacher5/data1/cyp/project/NewCap/checkpoints/clip-vit-base-patch32
export PARSER_CKPT=/home/teacher5/data1/cyp/project/NewCap/checkpoints/flan-t5-base-VG-factual-sg
export WTE_MODEL=/home/teacher5/data1/cyp/project/NewCap/checkpoints/all-MiniLM-L6-v2
export HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1
```

### 3.3 训练数据 pickle（自训时）

按 ViECap 流程准备，例如：

- `annotations/coco/coco_texts_features_ViT-B32.pickle`（`train_coco.sh` 使用）  
- `annotations/flickr30k/flickr30k_texts_features_ViT-B32.pickle`（`train_flickr30k.sh` 使用）  

相关脚本：`entities_extraction.py`、`texts_features_extraction.py`、`images_features_extraction.py`（详见原版 README）。

## 4. 如何训练

训练入口：`main.py` → `CaptionsDataset` + `ClipCaptionModel` / `ClipCaptionPrefix`。  
保存权重：`checkpoints/<out_dir>/coco_prefix-00{epoch}.pt`（脚本里 `out_dir=checkpoints/train_coco` 时，实验名由脚本名决定）。

### 4.1 COCO（约 15 epoch）

```bash
bash scripts/train_coco.sh 0
# 等价：DEVICE=0，写入 checkpoints/train_coco/
```

脚本要点：

- `--bs 80 --lr 0.00002 --epochs 15`  
- `--using_hard_prompt --soft_prompt_first`  
- `--using_clip_features` + `coco_texts_features_ViT-B32.pickle`  
- `--random_mask --prob_of_random_mask 0.4`  
- `--use_amp`

常用产物：`checkpoints/train_coco/coco_prefix-0014.pt`（第 15 个 epoch，编号 0-based → `0014`）。

### 4.2 Flickr30k（约 30 epoch）

```bash
bash scripts/train_flickr30k.sh 0
```

产物示例：`checkpoints/train_flickr30k/coco_prefix-0029.pt`。

### 4.3 训练注意

- 语言骨干默认 `gpt2`；离线时改为本地目录，并保证 `AutoTokenizer` / 模型可加载。  
- `--frozen_gpt`：只训 mapping（`ClipCaptionPrefix`）。  
- InvLM **不需要**为记忆库再训一遍 ViECap；用现成 `coco_prefix-*.pt` 即可做 InvLM 推理。

## 5. 如何推理与评测实验

### 5.1 单图：MeaCap InvLM

```bash
bash scripts/run_meacap_invlm.sh images/instance1.jpg

# 或手动
python viecap_inference.py \
  --device cuda:0 \
  --memory_id coco \
  --image_path images/instance1.jpg \
  --weight_path checkpoints/train_coco/coco_prefix-0014.pt \
  --using_hard_prompt \
  --soft_prompt_first \
  --language_model "$LANGUAGE_MODEL" \
  --vl_model "$VL_MODEL" \
  --parser_checkpoint "$PARSER_CKPT" \
  --wte_model_path "$WTE_MODEL" \
  --local_files_only
```

成功日志示例：`memory concepts: [...]` / `the generated caption: ...`。

### 5.2 单图：ViECap 基线（对比用）

```bash
python infer_by_instance.py \
  --device cuda:0 \
  --image_path images/instance1.jpg \
  --weight_path checkpoints/train_coco/coco_prefix-0014.pt \
  --language_model "$LANGUAGE_MODEL" \
  --using_hard_prompt --soft_prompt_first --prompt_ensemble \
  --name_of_entities_text coco_entities --threshold 0.4
```

### 5.3 批量：ViECap 基线

```bash
# 参数：<实验名> <GPU> <额外参数> <epoch>
bash scripts/eval_coco.sh train_coco 0 '' 14
bash scripts/eval_flickr30k.sh train_flickr30k 0 '' 29
bash scripts/eval_nocaps.sh train_coco 0 '--top_k 3 --threshold 0.2' 14
```

依赖预提取特征：`test_captions_ViT-B32.pickle` / `nocaps_corpus_ViT-B32.pickle`。  
指标：脚本末尾调用 `evaluation/cocoeval.py`。

### 5.4 批量：MeaCap InvLM

#### Flickr30k（推荐脚本齐全）

```bash
bash scripts/eval_flickr30k_meacap.sh train_flickr30k 0 '' 29

# 改记忆库 / 检索条数
MEMORY_ID=coco bash scripts/eval_flickr30k_meacap.sh train_flickr30k 0 '--memory_caption_num 3' 29
```

需要：`flickr30k-images/` 原图 + pickle + `data/memory/flickr30k/`（默认 `MEMORY_ID=flickr30k`）。

#### NoCaps

```bash
bash scripts/eval_nocaps_meacap.sh train_coco 0 '--top_k 3 --threshold 0.2' 14
```

需要：

- `annotations/nocaps/nocaps_corpus_ViT-B32.pickle`（soft prompt）  
- **原图** ViECap 布局：`annotations/nocaps/in_domain/0.jpg` 等（InvLM HF CLIP）  
- `data/memory/coco/`（默认记忆库）

缺图时会 `FileNotFoundError`；本分支请补齐图片或改回 ViECap 基线 `eval_nocaps.sh`（仅 pickle）。

#### COCO InvLM（本分支无专用 sh，手写 validation）

```bash
python validation.py \
  --device cuda:0 \
  --clip_model ViT-B/32 \
  --language_model "$LANGUAGE_MODEL" \
  --continuous_prompt_length 10 \
  --clip_project_length 10 \
  --using_image_features \
  --name_of_datasets coco \
  --path_of_val_datasets ./annotations/coco/test_captions.json \
  --image_folder ./annotations/coco/val2014/ \
  --weight_path checkpoints/train_coco/coco_prefix-0014.pt \
  --out_path checkpoints/train_coco \
  --using_hard_prompt \
  --soft_prompt_first \
  --use_meacap_invlm \
  --memory_id coco \
  --memory_caption_num 5 \
  --vl_model "$VL_MODEL" \
  --parser_checkpoint "$PARSER_CKPT" \
  --wte_model_path "$WTE_MODEL" \
  --local_files_only

python evaluation/cocoeval.py --result_file_path checkpoints/train_coco/coco*.json
```

### 5.5 提示与解码约定

| 模式 | 参数 |
|------|------|
| 推荐（与 ViECap eval 一致：软+硬） | `--using_hard_prompt --soft_prompt_first` |
| 仅硬提示 | `--using_hard_prompt --only_hard_prompt` |
| 仅软提示 | **不推荐**（易重复乱码） |

- InvLM 检索条数：`--memory_caption_num`（默认 5）  
- `top_k` / `threshold`：主要给 **ViECap 实体分类**；InvLM 路径基本不用

## 7. 常见问题

| 现象 | 处理 |
|------|------|
| `No module named 'viecap'` | 使用本仓库扁平导入的 `viecap_inference.py` |
| InvLM `FileNotFoundError: .../in_domain/0.jpg` | 补 NoCaps / COCO / Flickr 原图；或改跑 ViECap 基线（仅 pickle） |
| 记忆库找不到 | 检查 `data/memory/<memory_id>/` 三个文件 |
| 生成 “Eleven Eleven…” | 加上 `--using_hard_prompt`，勿只用 soft prompt |
| `unexpected keys (attn.bias)` | 旧 GPT-2 checkpoint 常见，一般可忽略 |
| 无 `eval_coco_meacap.sh` | 本分支已删；用 §5.4 手写命令 |
